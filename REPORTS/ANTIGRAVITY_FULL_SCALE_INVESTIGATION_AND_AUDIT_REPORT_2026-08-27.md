## 2. Deep-Dive Problem Analysis & Structural Fixes

### 2.1 The Vault Export/Import Button Styling Blocker
- **File:** `components.css` (Line ~3218)
- **Symptom:** The `.fearn-btn-backup` styling rules were present in the stylesheet, but buttons rendered with Chromium's fallback default gray `rgb(239, 239, 239)`.
- **Root Cause:** An orphaned, unclosed rule `.fearn-confirm-dialog-card { background: #0f172a;` preceded the liquid-glass modal section. Because the brace was never closed, the CSS parser remained in an open rule state until EOF, dropping every rule following it.
- **Fix:** Removed the orphaned partial rule (the complete, fully formed rule existed directly below). Parsed CSS rules increased from 381 to 431+, restoring the dark obsidian glass design system.

### 2.2 Theme Overrides for Sunlight, Vesper, and Twilight
- **File:** `theme.css`
- **Symptom:** Vault backup buttons on `sunlight` (Solar white background) and `vesper`/`twilight` (Sepia parchment background) lacked high-contrast theme overrides.
- **Fix:** Added targeted theme selectors:
  ```css
  .env-solar .fearn-btn-backup,
  [data-env="solar"] .fearn-btn-backup,
  .env-sunlight .fearn-btn-backup,
  [data-env="sunlight"] .fearn-btn-backup {
    background: rgba(0, 0, 0, 0.05) !important;
    border: 1px solid rgba(0, 0, 0, 0.15) !important;
    color: #1e293b !important;
  }
  ```

### 2.3 Streak Logging Click Event Propagation
- **Files:** `app.html` and `index.html`
- **Symptom:** Clicking the Anki or WaniKani "I did this today" button logged the streak but immediately popped the `#fearn-streak-calendar-modal`.
- **Root Cause:** Both buttons are nested inside `.fearn-streak-card`, which has an event listener triggering the calendar modal. Clicks bubbled to the parent container.
- **Fix:** Added `e.stopPropagation()` in both event handlers in both HTML shells.

### 2.4 Stripping Repetitive Boilerplate in 3 Curricula
- **Files:** `data/curricula/japanese.js`, `data/curricula/arabic.js`, `data/curricula/russian.js`
- **Symptom:** All 170 lessons in each of these three languages opened with a redundant, 600–1,250 character wall of meta-grammar text before reaching the actual lesson content.
- **Fix:** Safely stripped the byte-identical boilerplate string prefixes, restoring clean, directly readable prose to 510 lessons.
