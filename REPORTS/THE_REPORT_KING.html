1. Executive Overview & Founding Vision

FEARN is an ambitious, self-contained, offline-first personal mastery operating system and "whole-self school". It unifies 20 full-depth world languages, 6 strategic and cognitive skills, 3 university-level courses, and a 14-track periodized athletic conditioning program within a single client-side single-page application.

Operating under the core principle of client-side sovereignty, FEARN requires zero cloud backends, zero external APIs, zero build tools, and zero npm packages. Opening app.html bootstraps the entire universe instantly.

Everything in FEARN runs directly from vanilla HTML5, CSS3, and JavaScript (ES6+). The Service Worker (sw.js) and Web App Manifest (manifest.json) enable complete offline installation as a Progressive Web App (PWA).
