1. Executive Summary & Identity

FEARN is a local-first, zero-dependency sovereign learning environment designed to take a learner from foundational literacy to advanced mastery across 29 academic, linguistic, cognitive, and physical disciplines. Built with an obsidian liquid-glass aesthetic, FEARN operates with 100% functionality in offline environments (e.g. Airplane Mode during transcontinental flights) without requiring external servers, third-party authentication, or cloud dependencies.

2. Core System Architecture

  • Engine Spine (engine.js): Provides the shared storage, Spaced Repetition System (SuperMemo SM-2 interval scheduler), universal streak bookkeeping, journal telemetry logging, and modular registration hooks.
  • Decoupled Modular Architecture: Every curriculum, skill visualizer, and UI extension plugs in through standard contracts without mutating the central DOM layout.
  • Offline PWA Flight Suite (sw.js & focus-noise.js): Pre-caches 105 static application assets and generates algorithmic acoustic brown noise via Web Audio API for cabin rumble blocking.
  • Adaptive 5-Theme Engine: Seamlessly switches between Dark Glass, Night Flight, Daylight, Sepia, and High Contrast.
  • Sovereign Vault Synchronization: 1-click JSON backup export/import allows effortless cross-device progress sync across PC, iPad, and iPhone.
